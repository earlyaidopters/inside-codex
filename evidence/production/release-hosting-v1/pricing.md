# here.now pricing

Machine-readable pricing and limits for here.now.

Last updated: 2026-08-11
Canonical docs: https://here.now/docs#limits

here.now supports both no-account temporary publishing and account-owned permanent resources. Total storage is shared by published Site versions and current Drive files. Drive version history is retained by time window and does not count toward storage quota.

## Anonymous

- Price: $0
- Account required: No
- Storage: Temporary Site storage only
- Sites: Temporary Sites only
- Site Data: Not available
- Custom domains: Not available
- Drives: Not available
- Analytics: Not available
- Site version history: Not available
- Max Site file size: 250 MB
- Max Drive file size: Not available
- Site expiry: 24 hours
- Drive version history: Not available
- Publish rate limit: 60 / hour / IP
- Notes: Best for quick previews and temporary links. Claim the Site with an account to keep it permanently.

## Free

- Price: $0 / month
- Account required: Yes
- Storage: 10 GB total
- Sites: 500
- Site Data: Included for account-owned Sites
- Custom domains: 1
- Drives: 1
- Analytics: Upgrade required
- Site version history: Recorded — upgrade to browse, preview, and restore
- Max Site file size: 5 GB
- Max Drive file size: 500 MB
- Site expiry: Permanent, or custom TTL
- Drive version history: 7 days
- Publish rate limit: 60 / hour
- Notes: Best for individual agents and lightweight publishing/storage workflows.

## Hobby

- Price: $4 / month
- Account required: Yes
- Storage: 500 GB total
- Sites: 1,000
- Site Data: Included for account-owned Sites
- Custom domains: 5
- Drives: 5
- Analytics: Included
- Site version history: Included
- Max Site file size: 5 GB
- Max Drive file size: 500 MB
- Site expiry: Permanent, or custom TTL
- Drive version history: 30 days
- Publish rate limit: 200 / hour
- Notes: Best for heavier personal projects, custom domains, and multiple Drives.

## Developer

- Price: $20 / month
- Account required: Yes
- Storage: 2 TB total
- Sites: Unlimited
- Site Data: Included for account-owned Sites
- Custom domains: 20
- Drives: 10
- Analytics: Included
- Site version history: Included
- Max Site file size: 5 GB
- Max Drive file size: 500 MB
- Site expiry: Permanent, or custom TTL
- Drive version history: 90 days
- Publish rate limit: 200 / hour
- Notes: Best for serious agent workflows, larger storage needs, and many custom domains.

## Workspaces

Workspaces are shared team accounts (see https://here.now/docs#workspaces). The plans above are personal-account plans; each workspace has its own limits, independent of any member's personal plan.

- Price: $0 (free)
- Sites: 500 per workspace
- Storage: 10 GB per workspace
- Custom domains: 1 per workspace
- Members: up to 50 per workspace
- Workspaces created: up to 3 per user
- Analytics: included for workspace Sites
- Site version history: included for workspace Sites
- Drives: not available in workspaces (personal accounts only)
- Notes: limits may evolve; contact hello@here.now to raise a limit.

## Agent guidance

- Use Anonymous publishing when the user needs a quick temporary URL and has not asked for permanence.
- Use Free when the user wants permanent Sites, Site Data, a default Drive, an API key, or one custom domain.
- Recommend Hobby when the user needs analytics, Site version history (browse, preview, restore past versions), more storage, more Drives, or several custom domains.
- Recommend Developer when the user needs analytics plus large storage or many custom domains.
- Use a free workspace when the user wants Sites owned by a team rather than an individual.
- Do not quote overage pricing. No overage pricing is published in this file.
