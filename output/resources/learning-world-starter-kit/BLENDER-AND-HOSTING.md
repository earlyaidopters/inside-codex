# Agent-readable Blender and hosting guide

Research checked September 10, 2026. Verify current setup instructions before execution.

## Confirm the actual toolchain

Use an installed Blender integration or local Blender automation supported by this agent environment. Read the chosen plugin's current instructions. A plugin name does not prove its external application, dependencies or optional paid providers are configured. Make no paid generation call merely because a plugin supports it.

Before building the world, create one small test asset in Blender, save an editable .blend source, export a GLB, and load that exact file in the chosen browser renderer. Inspect scale, orientation, materials and animation where applicable. Mark's project used Blender with Babylon.js, TypeScript and Vite; a new project can choose a suitable equivalent and explain it.

## Build one complete lesson

Use clear asset names and separate source assets from runtime files. Keep lesson content and state separate from mesh names. A good render in Blender is not proof that the browser version looks right. Check each important asset under runtime lighting and camera angles. Prefer reproducible scripts and editable sources for later changes.

Give the learner one goal, an action that matters, visible feedback, and a way to recover. Support readable controls, keyboard use, pause and reduced motion as appropriate. Verify factual content against the supplied references. Anatomical visualization does not imply medical validity.

## Check before sharing

Run the actual learner journey and its meaningful failure paths. Inspect cold load, navigation, saved progress, retry, missing assets and the intended device layouts. Desktop phone emulation does not establish physical-phone performance. Record tests, actual limitations and specific fixes. Avoid arbitrary quality scores without evidence.

## Publish with here.now

Open https://here.now/docs and follow its current install/setup instructions. At this research lock, the documented skill command is:

    npx skills add heredotnow/skill --skill here-now -g

Use a permanent site under the user's account when requested; help complete sign-in without exposing credentials. Anonymous sites expire after 24 hours. Store credentials privately outside source repositories and screenshots.

Build the production output, publish only the required runtime directory, and open the returned live URL. Verify assets, navigation and downloads there. Keep an earlier release so changes can be recovered. Do not overwrite unrelated sites.

Suggested deployment prompt:

> Build the production version of this project and publish its output with here.now. Use a permanent site under my account, help me complete sign-in if needed, then open the live URL and verify the world, its assets and the download links.
