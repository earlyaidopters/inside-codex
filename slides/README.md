# Companion filming slides

Source snapshot of the separately managed `filming-site` working repository at this game's initial GitHub import. Its `.git` history and private `.openai` hosting configuration are deliberately excluded. The source site is static HTML/CSS/JavaScript authored directly under `dist/`; this directory is the editable application here, not a compiled game build.

Serve the dist directory at the origin root with a local static HTTP server. The existing hosted slides are at https://immersive-learning-worlds.markkashef.chatgpt.site/ (owner access may be required). These slides explain the planning process; they do not run the game. Changes here do not deploy either site automatically.
