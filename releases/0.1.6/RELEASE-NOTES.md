# Inside Codex 0.1.6 — Inside a save

One new optional deep dive, at Browser Lab (station 10). Click the miniature browser or Explore inside to separate Page, Action and Saved record. Save the owner, discover the missing write by reloading, repair the connection, and verify the correct owner after another save and reload.

Includes equivalent DOM and 3D inspection controls, an independent demonstration state, an approximately twenty-second example, pause/reset/return controls, motion preference restoration and a downloadable action receipt. This uses the existing deterministic browser simulator and makes no live server requests. The original lesson and completion rules remain intact.

The exhibit uses lazy procedural Babylon geometry and four filtered dynamic textures. Neighboring tool and automation props temporarily leave the scene while the browser expands, and return with their state afterward. No Blender re-export or external generation service was needed.

Validation and visual findings are recorded in evidence/browser-depth-v1/ASSESSMENT.md. The hosted file manifest and archive hashes are retained beside this note.
