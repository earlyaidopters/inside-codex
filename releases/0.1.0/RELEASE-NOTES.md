## What players can learn

1. Assemble a model, relevant context, tools and verification into a working agent loop.
2. Resolve conflicting source facts, inspect a captured error and check the saved output.
3. Choose model and effort from the task and actual checks; distinguish missing access from insufficient reasoning.
4. Separate execution scope, approval and connector access, and verify an unsent draft.
5. Request a focused task with an outcome, verification, chosen effort and a pin.
6. Reproduce shared-file interference, use separate worktrees, compare and verify integration.
7. Steer active work and queue a dependent follow-up at appropriate boundaries.
8. Find regressions hidden by a narrow check and inspect the repaired diff.
9. Inspect plugin contents, connect a source tool and repair a skill that fails on a second client.
10. Reproduce browser data loss and verify persistence by saving and reloading.
11. Rehearse a precise recurring workflow, quiet/actionable outcomes, failed reads and host recovery.
12. Preserve a verified release, expose a delivery-only failure and restore a checked package.

## Controls and recovery

Use the map or numbered mission controls to navigate. Drag the world, focus the canvas and press arrow keys, or scroll/pinch to look around. Return to guide restores the authored view. Camera clearance constrains orbit against the room bounds; this is local exhibit exploration, not unrestricted first-person walking.

Settings offers High/Balanced graphics, reduced motion, master mute and four audio channels. The default is muted. Captions, skip voice and the exercise panel provide a route without audio. Escape closes a dialog or pauses/resumes. Export progress before clearing browser data or moving to another origin/device. Import is explicit.

If a view appears stuck, check Pause/Resume, try Return to guide and use the displayed retry for an interrupted asset load. Choose Balanced when High is slow. Preserve/export progress before clearing data. To report a problem, include the mission/step, action, expected and actual result, browser/device, graphics setting and a screenshot.
